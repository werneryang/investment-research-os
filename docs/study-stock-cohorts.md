# 股票群组研究：新股与热门股在不同市场状态下的表现（设计草案，2026-11-19）

> 状态：讨论草稿，未实现，未登记研究。数据来源尚未选定（见 §5），选定前只能做第 0 阶段。

「股票群组」指按事先写明的规则筛出的一组股票，例如某段时间上市的全部新股，或某个日期满足「热门」条件的股票。研究它们之后的表现，以及表现是否随市场状态不同而不同。

## 1. 回答什么

| 研究 | 问题 | 不回答 |
| --- | --- | --- |
| 新股上市后表现 | 美国新股上市后 1、3、6、12、36 个月的回报，相对基准的差异；不同市场状态下上市的批次之间差异多大 | 单只新股值不值得买；发行定价是否合理；承销商行为 |
| 热门股后续表现 | 按规则认定为「热门」的股票，此后 1、3、6、12 个月相对基准的回报；不同市场状态下差异多大 | 哪只股票现在是热门、该不该追；「热门」的成因 |

两项都是描述研究（`result_type: descriptive`），写明不作因果解释，历史统计不等于预测。要检验「按某条规则买卖能否获利」，属于「预测与信号 · 策略模拟表现」，需要样本外检验与可交易性假设，不在本设计内。

## 3. 共用部分：市场状态

两项研究都要按「事件或认定日所处的市场状态」分组。这部分只定义一次，放在公共分析代码里（拟 `analytics/market_state.py`，按 README 的研究计算改动走 PR），状态规则登记在配置中，有版本号，研究引用规则 id 与版本。

### 3.1 候选状态维度

只列现有已接入数据就能算的维度；具体用哪几个、阈值多少，由方法库给出依据后再定。

| 维度 | 候选划分 | 已有数据 | 限制 |
| --- | --- | --- | --- |
| 趋势 | 指数距前高的回撤是否超过某阈值；指数相对过去 12 个月均值的位置 | `fred_nasdaqcom`（1971 年起）；`fred_sp500`（只有最近 10 年）；Shiller 月度标普综合指数 | FRED 指数是价格指数，不含股息；标普 500 日度序列太短 |
| 波动 | VIX 处于历史分位的哪一段 | `fred_vixcls`（1990 年起） | 有版权，只在本机使用；分位用截至当日的历史计算 |
| 经济周期 | 是否处于 NBER 认定的衰退月份 | `fred_usrec` | 事后认定，宣布时滞常达数月到一年以上，只能用于事后分组 |
| 新股市场冷热 | 过去若干个月新股数量相对历史的高低 | 需第 0 阶段先取得新股清单 | 只适用于新股研究 |

### 3.2 两种口径必须分开

- **事前状态**：只用认定日当天及以前已经公布的数据判断。例如回撤、VIX 分位用截至当日的值。能回答「当时看得见的状态下，之后表现如何」。
- **事后状态**：用事后才知道的信息分组，例如 NBER 衰退月份、事后确认的牛熊区间。只能回答「处在后来被认定为某种状态的时期里，表现如何」。

页面和结果里每个分组都标明是事前还是事后。事后分组不得放进任何看起来像信号的展示。

## 4. 两项研究的口径

### 4.1 新股

- **样本**：美国交易所的普通股首次公开发行。剔除 SPAC、ADR、单位证券、REIT、封闭式基金、直接上市（直接上市可单列，不并入）、发行价低于某个下限的股票。剔除规则写在登记里，被剔除的逐条留记录。
- **事件日**：首个交易日。发行价与发行日取自 SEC 申报（424B 招股说明书）；首个交易日需要行情数据核对，两者不一致的列出。
- **回报口径**：分别从发行价和首日收盘价起算；首日回报单列。回报含股息，按复权价计算。
- **基准**：市场指数（含股息的可得版本）；可选按规模或行业匹配的基准，方法依据由方法库提供。
- **批次**：按上市月份或季度成批，市场状态按事件日认定。
- **退市**：退市前的最后价格与退市原因都要记录；退市后回报怎么处理是本研究最大的口径问题，见 §6。

### 4.2 热门股

- **「热门」的定义**必须只用认定日以前可得的数据，并在登记里写死，例如「过去 N 个交易日成交额排名前 X% 且涨幅超过 Y%」。不允许看完结果再调定义；要比较多种定义时，全部定义事先登记，结果全部展示。
- **股票范围**：认定日当时在市的全部股票，而不是今天还在市的股票。
- **认定频率**：月末认定；同一只股票在连续月份重复入选时，各期分别计，但在结果里标明重叠程度。
- **回报口径与基准**：同新股。

## 6. 主要限制

- **幸存者偏差**是这两项研究成败的关键。免费行情来源通常缺少已退市股票，而新股和热门股中退市比例都不低。缺退市股票会系统地高估回报。第 0 阶段要先量化缺失比例；缺得太多，研究只能写「不能回答」。
- **基准选择改变结论。** 长期超额回报对基准（市场、规模匹配、行业匹配）很敏感，至少并列两种基准。
- **重叠样本。** 36 个月持有期的批次互相重叠，统计检验要按重叠处理，不能把月度批次当独立样本。
- **状态分组的样本量。** 衰退月份、极端高波动时期很少，分组后样本可能只有几十只股票或几个批次，结果页显示每组样本量，样本不足的分组不给结论。
- **市场范围。** 只做美国。其他市场需要另行核验来源，不由本设计推及。
