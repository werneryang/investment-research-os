# 现有 15 家公司的年度财报研究

以本机已经保存的 EDGAR E1 样本为边界，不等待全市场扩容。入口为 `studies/company_sample/`，每家公司有固定地址 `studies/company_<slug>/`。总览列最新财年数据及可比性；公司页提供营收、经营/净利润率、经营现金流、现金资本开支曲线、逐年表与可展开的申报证据。

## 数据和计算

- 原始来源：[SEC FSDS](https://www.sec.gov/data-research/sec-markets-data/financial-statement-data-sets) 与 [Company Facts](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。只读取本机已有分区，不重新下载或改写原始数据。
- `scripts/prepare_company_research.py` 生成自包含证据包，登记为 `company_sec_facts`。快照日期、分区版本、内容校验值、原始来源路径及校验值、公司口径配置和全部选中申报版本随包固定。普通序列存储仅作版本运输；财年起止、科目和版本以证据记录为准，不能套用日历年推算。
- 年度限定 10-K/10-K/A、USD、合并口径、4 季度；API 有起止日时再检查 350–380 天。FSDS 无起点时明确记为未知，不能冒充实际期间已逐条核验。月末匹配键对齐来源，实际期末另列，不把财年期末年份叫作共同日历年。
- 五个原始指标：营收、经营利润、归母净利润、经营现金流、购建固定/生产资产的现金支出。公司没有对应标准科目时记缺失，不推导补齐或把自定义科目猜成等价科目。
- 同份申报优先采用 FSDS 主报表科目，再按登记别名排序；只有 API 时按别名排序并在证据中标来源。此规则避免宝洁 2012 年 `Revenues` 的 28.4 十亿美元披露数覆盖主报表 `SalesRevenueNet` 的 82.006 十亿美元比较数。API-only 仍有口径风险，后续人工核查不能省略。
- 同一事实键在原始分区有不同数值时停用该值并标记冲突；最新申报存在冲突时不退回旧值掩盖问题。每份申报保留其他候选科目与数值。
- 利润率 = 利润 / 正营收；经营现金流率、资本开支强度同理。只有两个数值属于同份申报才计算。派生现金余额 = OCF − 非负现金资本开支，不等于可分配现金，也不包括融资租赁新增资产。
- 同比仅比较相邻财年、同一申报、同一科目且上年基数为正的数值。期间断档不跨年计算，不把科目变化算成增长；同比可能与逐年最新值曲线的比值不同，配对分子分母和申报编号保存在结果中。
- 同科目历次申报数值改变标为**修订候选**；跨科目变化单列。既不把 10-K/A 自动视为数值重述，也不把同科目改值自动认定会计错误。业务分拆、终止经营及会计准则转换都可能导致重列。

## 可比性

`config/company-research.yaml` 是本研究的公司说明与有限对照关系。Walmart/Costco 是样本内较接近的零售对照，仍有会员模式和财年差异；Amazon 的零售与云业务需要分部资料才能作更严密比较。Microsoft/Alphabet/Amazon 可观察云基础设施投入方向，但合并利润率不是纯云业务利润率。Apple/NVIDIA 的外包模式不适合与自营制造商直接按资本开支排名。消费品牌组仅作方向性比较。

JPMorgan 与 Berkshire 单独研究；保留报表原值和自身净利润率，但禁用普通企业式经营利润率、现金流率、资本开支强度及 FCF。Tesla、Exxon、J&J 在样本内没有直接同业。全部 15 家都不提供“最优公司”排名。

Alphabet 当前 CIK 的后续年报含 2013 年起比较数，保留这些数值与真实申报时间；未拼接前身 Google 另一 CIK 的完整历史。NVIDIA 早期 capex、JPMorgan capex 以及部分公司的经营利润缺标准科目，保持缺失。

## 更新、验证与发布

```bash
uv run python scripts/prepare_company_research.py
uv run python scripts/run_company_research.py
uv run iros site --out _site
```

运行脚本执行总览及 15 家公司研究，并逐个验证固定版本复现；失败会停止，不将失败当成缺失研究。研究结果状态为 `partial`，表示样本、口径或支持范围受限，不表示程序未交付。技术测试、固定输入复现与人工年报核验分别报告。

按 README 开发流程提交代码；已验证运行的 manifest、result 和报告归档到 `archive` 分支后，Pages 从档案恢复这 16 项研究。CI 无需下载全部 EDGAR。原始 EDGAR 与输入证据包沿用现有来源登记的本地保存边界，不归档公开原始数据；公开结果含研究所用数值、申报链接和版本证据。远端档案可以核对产物完整性，重新计算仍需本地固定输入版本。页面可离线浏览，英文版提供英文表头和方法提示，公司具体备注与完整报告为中文。

## 本次交付核对（2026-10-26）

快照为 2026-10-24：15 家、257 个公司年度期间、1,285 个指标位置，1,181 个有值、104 个缺失；138 个同科目修订候选、60 个跨申报科目切换。独立读取原始 Company Facts JSON，按 CIK、科目、USD、accession、实际期间起止核对全部 1,181 个最新非空值：1,181 个一致，0 个不一致，0 个无法测试。此核对检查提取一致性，不等于逐条人工审阅原始年报，也不能确认所有修订的会计原因。运行管道的通用 `raw_spot_check` 不支持证据包，仍如实显示 skipped；本次专项原始 JSON 核对记录在本地 `data/company-research/raw-audit.json`。

全部 16 项研究已完成固定版本重算。负向测试覆盖跨申报比率、缺失和非正基数、跨科目增长、缺年、银行指标隔离、重复事实和证据变化；网页实际检查了窄屏表格和深色模式趋势图。
