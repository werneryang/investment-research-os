# 研究方法提取模块

> 状态：**初版（2026-11-05 确定范围）**，只有文档，没有代码。
> 英文名：AI Equity Research Methodology Extraction。

## 目标

从公开研究中学习分析师如何提出问题、寻找证据、建立可被推翻的假设，并整理成可用于其他公司的方法。

本模块不收集投资建议，不学习目标价，也不产生研究结论。

## 目录

| 位置 | 内容 |
| --- | --- |
| [methods/](methods/README.md) | 方法卡：与具体公司无关的分析方法 |
| [records/](records/README.md) | 记录：从材料提取论证，或把方法用到一家公司 |
| [playbooks/](playbooks/README.md) | 判断登记：可检验的说法，到期用官方数据核对 |
| [sources.md](sources.md) | 来源条款的核对状态与可用范围 |

## 边界

1. **单向依赖。** `src/`、`config/`、`site/` 不读取本目录。本模块可以使用项目的公开数据，反向不成立。
2. **不接入研究体系。** 不进 `config/studies/`，不登记来源与数据集，不上网站，不算研究成果。
3. **初版不写代码。** 只维护 Markdown 与 YAML；流程稳定后再考虑提取脚本。
4. **不依赖付费 AI。** AI 只做一次性辅助，产物人工入库，CI 不运行。
5. **不改公共契约。** 本目录的改动按 README「开发流程」的普通改动处理。

## 公开边界

**本仓库是公开仓库，提交到 `main` 等于公开发布。** 与网站隔离不代表私密。

| 内容 | 位置 |
| --- | --- |
| 自己写的方法卡，只含结构，不含报告数字 | 本目录 |
| 公开来源的提取记录，条款已核对且用自己的话写 | 本目录 |
| 报告原文、PDF、截图、大段引用 | 仓库外的私有目录 |
| 订阅报告的提取记录 | 仓库外的私有目录；条款确认前不入库 |

入库前先查 [sources.md](sources.md)。未核对的来源，提取记录不入库；方法卡只保留自己写的结构，核对后再复查。

## 工作规则

- **分层保存。** 原文事实、作者判断、AI 推导、自己的延伸分别标记，不能混写。
- **推理不算已校验。** 事实和作者判断可以回原文核对；因果机制与可迁移性是解释，始终标为推导。
- **检验判断，不检验方法。** 分析框架无法回测。方法产生的具体说法登记到 `playbooks/`，到期核对。
- **同时收集反例。** 除获奖报告外，也要收集事后证明错误的报告和同一公司的多空对照。
- **获奖不等于有效。** 比赛报告是结构样本，不是方法有效的证据。

## 初版

前提：系统先用于帮助使用者学习和做研究，人做判断，AI 负责提取、查找和核对。这项前提改变时，范围要重新确定。

| 部分 | 初版只做 | 暂缓，直到 |
| --- | --- | --- |
| 来源 | 公开申报、书籍、个人输入 | 这 3 类都走通 |
| 结构 | 记录、方法卡、判断登记，不新增目录 | 记录多到难以管理 |
| 分类 | 方法类型 `kind`；业务模式自由填写 | 约 20 条记录后再归纳 |
| 合并 | 只和方法库对照：符合、扩展、冲突或新方法 | 出现真实的重复方法 |
| 适配 | 只用方法卡的“适用 / 不适用” | 同一方法用到第 3 类业务 |
| 现实对接 | 手工登记判断，到期手工核对 | 登记量大到手工做不过来 |

第一批材料：

1. 公开申报：ADP 代理权争夺材料（2017 年，维权方 DFAN14A 与公司方回应）。
2. 书籍：一本方法书的一章。
3. 个人输入：一条自己的研究想法。录入时增加来源类型 `own`。

## 工作流程

| 步骤 | 完成标准 |
| --- | --- |
| 1. 选材料 | 写明为什么选它，属于哪类来源 |
| 2. 查条款 | 在 [sources.md](sources.md) 中允许入库；未核对就先核对 |
| 3. 提取 | 按 [records/](records/README.md) 的层级写完，AI 辅助要写明 |
| 4. 回原文核对 | 事实与作者判断都有位置，核对后才标 `verified: true` |
| 5. 和方法库对照 | 每个方法都标明符合、扩展、冲突或新方法，并完成对应动作 |
| 6. 写出判断 | 至少尝试写一条可检验的判断；写不出就说明原因 |
| 7. 登记到期日 | 判断进入 `playbooks/`，有指标、数值或方向、检查日期 |

## 提取质量

- **人工对照**：同一份材料，人工提取一次，AI 提取一次，比较差异。
- **稳定性**：AI 隔一段时间重新提取一次，比较结果。

两种比较都记在对应记录的 `extraction.quality_notes`。

## 初版验收

- [ ] 3 份不同类型的材料走完全流程
- [ ] 至少 1 份做过人工与 AI 的对照
- [ ] 至少 1 张方法卡因此被修改，或发现 1 个新方法或冲突
- [ ] 登记至少 5 条有明确到期日的判断

验收只看流程是否走通，不要求证明方法能预测。判断到期后再核对。

## 进入正式研究

方法达到 `validated` 且步骤可用公开数据复现后，可以写成正式研究进入 `config/studies/`。并回项目的只有这项研究，本模块本身不并入。
