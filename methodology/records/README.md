# 提取记录

一份材料一条记录，从 [_template.yaml](_template.yaml) 复制，文件名用 `<来源>-<标的>-<日期>.yaml`。

记录的目的不是摘要，而是把论证拆开：作者研究什么问题，用什么证据，怎样推到财务结果和估值，什么情况下判断会错。

## 分层

每条内容必须标明层级：

| 层级 | 含义 | 必须有原文位置 | 可以标 `verified: true` |
| --- | --- | --- | --- |
| `source_fact` | 材料中陈述的事实 | 是 | 是，回原文核对后 |
| `author_judgment` | 作者的判断或推理 | 是 | 是，只表示作者确实这样说 |
| `ai_inference` | AI 重组或推导的内容 | 否 | 否 |
| `own_extension` | 自己提出的延伸问题 | 否 | 否 |

`verified: true` 只表示“与原文一致”，不表示内容正确。

计算结果放在 `method_output`：披露值、推算值、估算值分开，估算值标 `estimate: true`。

## 入库前检查

- 来源在 [sources.md](../sources.md) 中允许入库。
- 全部用自己的话写，不贴大段原文，不抄研报里的数字；需要时只记位置。SEC 申报的公开数字可以入库，但要写明申报编号和位置。
- 正确性存疑的指控类内容，只写成“需要核实的问题”。
