# 财报发布后的市场反应检验

## 回答什么问题
市场对这次财报和指引的解读是什么？初始反应是否持续？

## 适用 / 不适用
- 适用：所有发布季度财报的公司
- 不适用：流动性很差的小型股（价格反应噪音太大）

## 所需数据
| 数据 | 来源层级 | 获取方式 |
|---|---|---|
| 发布日期与时间（盘前/盘后） | official | 8-K 提交时间（EDGAR） |
| 日收益率：个股、基准指数、同业组 | structured | 公开行情 |
| 次日新闻与评论 | commentary | 新闻检索，只记录观点类别，不转载原文 |

## 步骤
1. 确定事件日：盘后发布则以次一交易日为第 0 天。
2. 计算超额收益：个股收益 − 同业组或基准指数收益，窗口取第 0 天、第 0–1 天、第 0–5 天、第 0–20 天。
3. 判断反应是否持续：第 0–20 天的超额收益与第 0 天同号且幅度未大幅回吐？
4. 记录市场关注点：从次日新闻中归纳 2–3 个被反复提及的点（例如指引、毛利率、资本支出）。
5. 与 earnings-quality-checklist 的结论对照：市场关注点和你的检查结果是否一致？

## 输出格式
```yaml
event_date: 2026-00-00
timing: after_close
abnormal_return:
  d0: 0.000
  d0_1: 0.000
  d0_5: 0.000
  d0_20: 0.000
persistent: null      # true / false
market_focus: []
consistent_with_checklist: null
```

## 判断规则与常见误读
- 初始大涨后回吐，说明市场最初高估了指引的意义，或其他因素（宏观、板块）抵消了利好。
- 必须扣除同业组和大盘的同期变动，否则会把板块行情误当作财报反应。
- 新闻只用于归纳关注点，不作为事实来源。

## 推翻条件
- 本方法本身是测量工具，没有投资结论；但若超额收益的计算基准选错（例如用大盘代替同业组），结论需重算。

## 来源案例
Ryan 的例子：某公司在电话会上给出很高的下一年营收增长指引，次日股价大涨，之后又回到公布前的水平。他因此除了读财报，还会收集当天和次日的市场新闻。具体涨幅为口述，未核实。

## 待验证事项
- 用你网站已有的 15 家公司，回溯最近 4 次财报，建立反应数据，检验"初始反应持续性"的比例。
