# 事件对产业链的暴露映射

## 回答什么问题
同一个事件，对产业链上不同环节的影响方向和传导路径分别是什么？

## 适用 / 不适用
- 适用：政策变化、需求冲击、原材料价格大幅波动、技术替代等影响整条产业链的事件
- 不适用：只影响单一公司的事件（管理层变动、诉讼）

## 所需数据
| 数据 | 来源层级 | 获取方式 |
|---|---|---|
| 产业链分层 | — | peer-layer-comparison 的 `peers/*.yaml` |
| 各公司收入暴露度 | official | 10-K 分部、终端市场、客户集中度披露 |
| 事件前后股价 | structured | 公开行情（用于事后检验，不作为推理依据） |

## 步骤
1. 用一句话定义事件和它直接改变的变量（例如：新建数据中心审批放缓 → 新增容量减少）。
2. 对每一层写出传导路径：变量变化 → 该层的收入/成本/定价权如何变化。
3. 判断方向（利好 / 利空 / 中性）和时滞（立即 / 1 年 / 2 年以上）。
4. 用收入暴露度给方向加权：该事件相关业务占公司收入多少？
5. 事后记录实际股价反应，检验映射是否正确，偏差写入备注。

## 输出格式
```yaml
event: "数据中心新建审批收紧"
changed_variable: "2028 年后新增容量"
layers:
  - layer: hyperscalers
    path: "资本支出放缓 → 自由现金流改善"
    direction: 利好
    lag: 立即
  - layer: data-center-reits
    path: "新增供给减少 → 续约议价能力提高"
    direction: 利好
    lag: 1-2 年
  - layer: independent-power
    path: "新增售电需求预期下修"
    direction: 利空
    lag: 2 年以上
exposure_weighting: "按相关业务收入占比"
ex_post_check: {date: "", matched: null, note: ""}
```

## 判断规则与常见误读
- 先写传导路径，再判断方向；直接凭直觉给方向容易漏掉二阶效应（例如供给减少对存量资产是利好）。
- 同一层内的公司暴露度差异可能很大（例如电力设备公司的数据中心收入占比各不相同），必须加权。
- 事件当天的股价反应只能作为事后检验，不能作为推理依据。

## 推翻条件
- 事件的直接变量没有发生变化（例如政策最终未实施）。
- 事后检验显示多个环节的实际反应与映射方向相反，需检查传导路径。

## 来源案例
讲者对同一事件的判断：科技巨头（资本支出放缓）、数据中心 REITs（存量租约更有利）受益；独立电厂、电力设备、新型云服务商（依赖新增扩建）受损。这些是讲者观点，事件本身（选举结果和政策内容）需另行核实。

## 待验证事项
- 用该事件做第一次事后检验：记录各层公司在之后一季的营收指引变化，而不只是股价。
