# Investment Research OS

个人投资研究与决策系统。当前阶段为架构设计；软件功能与数据接口尚未实现或验收。

## 当前设计基线

[个人投资研究与决策框架 V0.2](docs/architecture.md) 是后续需求细化与开发的当前依据。美国税务居民、美元本币等使用条件在文档中列为待确认假设。

建设顺序：账户与数据核算 → 基础配置与风险监控 → 账户与税务检查 → 研究模型验证 → 渐进扩展。
